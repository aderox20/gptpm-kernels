# GPTPM Kernels

Static kernel manifests and release artifacts for GPTOS.

The GitHub Pages site is deployed automatically from `main`:

https://aderox20.github.io/gptpm-kernels/

Publish a kernel by adding the versioned `vmlinuz`, modules archive, checksum
file, and updating `latest/linux.json` or `latest/linux-lts.json`. If you want more information about the Package Manager you should check out: [GPTPM Github Repo](https://github.com/aderox20/GPT-PackageManager)
